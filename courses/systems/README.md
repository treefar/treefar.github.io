# 115-1 課堂互動系統

2026-09-28，`source_agent: codex`。私網原有互動系統整理成五套可直接開啟的公開學生版，供三門課第 4～6 週使用。這個目錄只存公開課堂內容；原私網站台與存取設定未改。

| 課程 | 第 4 週 | 第 5 週 | 第 6 週 |
|---|---|---|---|
| 人工智慧與互動媒體特論 | 遊戲演算法速查 | 五工具組合拳 | 水龍頭合成器 |

每週頁面在投影片加入系統入口，在講義加入簡介、操作任務與交付物。入口路徑固定為 `../systems/<slug>/`。

公開版處理：移除私網來源、裝置路徑與個人識別文字；像素工具頁的三組裝置代號匿名化；敘事頁改為明確標示架空人物與校園。五套系統設 `noindex, nofollow`，學生有連結即可開啟。故事示範依賴 React、React DOM 與 Babel 的外部 CDN；首次載入可能比其他四套慢，建議以桌機或筆電操作。

驗證：`node courses/systems/verify.mjs` 通過九週入口、五套系統、相對資源與公開內容檢查；九張投影片瀏覽器量測無內容溢出。2026-09-28 GitHub Pages 提交 `89e02ae` 建置成功，九個週次與六個系統入口頁（含總覽）線上皆為 HTTP 200，內容標記與本次版本相符。

後續改課時，先改週頁與對應學生版，再跑 `verify.mjs` 並抽看畫面；若來源私網系統更新，不能直接覆蓋已匿名化的學生版。
