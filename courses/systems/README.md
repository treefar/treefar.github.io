# 115-1 課堂互動系統

2026-09-28，`source_agent: codex`。盤點私網 `tools/pages.json` 的 111 筆頁面及公開站首頁的工具卡片，依三門課第 4～6 週主題安排一週一套系統。五套公開學生版存於本目錄；三套原本就公開的工具直接連正式網址。

| 課程 | 第 4 週 | 第 5 週 | 第 6 週 |
|---|---|---|---|
| 人工智慧與互動媒體特論 | 遊戲演算法速查 | 五工具組合拳 | 水龍頭合成器 |
| 遊戲企畫 | [遊戲名詞大百科](https://treefar.link/game-glossary/) | 架空校園分支敘事 | [第一性原理導航器](https://treefar.link/first-principles-navigator/) |
| 專題企畫 | [像素地圖編輯器](https://treefar.link/pixel-city-editor/) | 架空校園分支敘事 | 遊戲演算法速查 |

每週頁面都在投影片與講義放入同一系統的入口、簡介、操作任務及交付物。遊戲百科供類型與競品分析；第一性原理供概念假設驗證；地圖編輯器供場景與關卡配置探索，輸出不當作正式美術。

## 其他查到的可操作系統

| 系統 | 入口 | 本輪用途 |
|---|---|---|
| [Steam 標籤定位器](https://treefar.link/steam-tag-prompter/) | 公開站 | 可接在遊戲百科後做標籤與競品定位；未占用第 4～6 週的每週主系統名額。 |
| [VN Studio 視覺小說製作系統](https://treefar.link/vn-studio/) | 公開站 | 可作敘事實作延伸；第 5 週主系統仍是分支敘事示範。 |
| [風格庫](https://treefar.link/style-library/) | 公開站 | 可作專題美術提案參考；第 4 週主系統是可操作的地圖編輯器。 |
| 脈衝防禦 | `pulse-core/` | 可作玩法原型分析延伸。 |

私網 `tilemaker-dot` 是 TileMaker DOT 工作流介紹頁，與已公開的像素地圖編輯器是不同項目；本輪學生操作使用後者。`game-proto-lab` 等內部決策頁未直接公開作為課堂入口。

## 公開版與驗證

本目錄五套學生版移除私網來源、裝置路徑與個人識別文字；像素工具樣本名稱匿名化；敘事頁明示人物與校園皆為虛構。五套設 `noindex, nofollow`。故事示範依賴 React、React DOM 與 Babel 外部 CDN，首次載入可能較慢。

`node courses/systems/verify.mjs` 檢查九週入口、本地資源與公開內容。三套站外工具須另以瀏覽器驗證公開可用。若來源私網系統更新，不能直接覆蓋已匿名化的學生版。
